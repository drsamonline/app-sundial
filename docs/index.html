an almanac for one day

Sundial

The day is an arc. An event is a shadow on it — where it falls is when it starts.

sunrise 06:00sunset 18:00

What it does

Drag a shadow along the arc and its start time changes; the length of the shadow is the duration, and dragging never changes it. The hour marks and the shadows are computed from the same arc, so a position and a time cannot disagree.

What it refuses

A shadow that runs past sunset is clipped and marked — the day ends, and the app does not pretend otherwise.
