Sundial

A calendar you schedule by drawing shadows. The day is an arc from sunrise to sunset; an event is a shadow on it. Where the shadow falls is when it starts, and how long it is is how long it lasts.

Open Sundial
Status Built and working: an arc from sunrise to sunset with its own hour marks; events drawn as shadows with a start and a length; dragging a shadow changes when it starts and never how long it lasts; and the day survives a reload with no network.
Release: Windows EXE, Android APK and Linux binary, built from this source in CI — app-latest.
Not built: real solar geometry. The arc is a simple window between two times you can set, not a computed sunrise for your latitude — said here rather than implied by the shape.

What it does

  • Draws the day as an arc, with hour marks computed from the same arc the shadows use.
  • Adds an event as a shadow: a position on the arc and a length in minutes.
  • Drags a shadow to a new position — the start moves, the duration does not.
  • Exports and re-imports the day.

What it will not do

  • Stretch a shadow when you move it. A duration is the length of the shadow.
  • Let a position and an hour disagree. Both come from one function.
  • Run past sunset. A shadow that would is clipped, and marked as clipped.
  • Grow a second job. No tags, reminders or search.
  • Use the internet. No fetch, no endpoint; CSP connect-src 'none'.

When things go wrong

CaseWhat happens
Bad inputNo name, no length, a zero length, an event outside the dial, a dial where the sun sets before it rises — each refused with the field named.
No networkNothing changes; the day is on the device.
Storage full or unavailableNOT SAVED, and the dial on screen is unchanged.
Corrupt saved stateReported and offered for export; never replaced with an empty one — an empty dial looks like a clear day.

How to run it

  • Here: play/index.html, or install it from your browser's menu.
  • Offline file: open docs/play/index.html straight from disk.
  • Tests: node tests/self-tests.js.
