Sundial

A calendar you schedule by drawing shadows. Where the shadow falls is when it starts; how long it is is how long it lasts.

Moving a shadow changes when it starts. It never changes how long it lasts.

    Sundial keeps the day on this device. The dial's hour marks and the shadows are computed from the same arc, so a position and a time cannot disagree. No astronomy, no network — just an arc from sunrise to sunset.
